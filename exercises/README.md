# Exercises

Carpeta para guardar ejercicios Java.

Cómo organizar:
- Crea una carpeta por ejercicio, por ejemplo `exercises/exercise1/`.
- Dentro, guarda `Exercise1.java` con la clase pública y `main` opcional para pruebas.

Cómo compilar y ejecutar desde la raíz del repo:

1) Compilar:
   cd exercises/exercise1 && javac Exercise1.java

2) Ejecutar:
   java Exercise1

(Repite los pasos para cada carpeta de ejercicio)

Sugerencias:
- Puedes usar paquetes y un build tool (Maven/Gradle) cuando el repositorio crezca.
- Añade tests con JUnit en una estructura `src/test` si quieres automatizar comprobaciones.
